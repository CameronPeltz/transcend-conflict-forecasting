Datasets, approaches, results, analysis, and next steps: everything tried to close the gap to 80% precision

Consolidates every dataset and modeling approach tested against the real, DARPA-specified task (discrete UCDP events at PRIO-GRID cell / 10-14 day granularity) — what helped, what didn't, and why, each backed by a real number from a genuinely held-out, never-look-ahead test, not a cross-validation estimate.

Core

The base task

Real UCDP GED v26.1 events (ucdp.uu.se, CC BY 4.0, no login), assigned to real PRIO-GRID cells (~55km, verified 99.99% match against UCDP's own field), 19 countries across DARPA's three named regions. 228,851 (cell, weekly issue date) candidate rows, 464 active cells, forecasting whether at least one event occurs within 10 days / 14 days of each issue date.

Integrated and tested

Six additional real data sources

GDELT 2.0 historical event streamFree, no registration

A real 2015–2025, 19-country pull (29.7M events, 3,981 days, 99.5% retrieved), aggregated to country-week tone/volume and joined never-look-ahead. Result: the largest real gain of any lever tested — see Tab 03.

ACLED civilian-targeting aggregatesFree (HDX), no registration

Country-month event/fatality counts. Result: added essentially nothing (round 2 finding, reproduced).

WorldPop gridded populationFree, no registration

Real 100m population-count rasters, windowed-summed over each cell's real footprint. Download in progress (throttled server, ~2 minutes/country) — result to follow.

CHIRPS monthly rainfallFree, no registration

Real global monthly rainfall rasters, 2015–2025 (131 files), windowed-averaged per cell, joined by the prior completed calendar month (100% match rate). Small, real gain: +0.3 points precision at both horizons on the frozen holdout — see Tab 03.

UNHCR asylum-application dataFree, no credentials

Real country-of-origin asylum application counts, 2013–2025, joined by the prior completed year (annual granularity, lagged a full year to stay never-look-ahead). 15 of 19 countries returned real records; 4 (Myanmar, Sudan, Eritrea, Haiti) returned none under the ISO3 codes queried — disclosed as an unresolved code-mapping gap, not silently dropped. Small, real gain: +0.6 points (10-day) / +0.8 points (14-day) on the frozen holdout, despite the coverage gap — see Tab 03.

Local LLM reasoning layer (Ollama, llama3.1)Free, local, no per-call cost

Not a dataset in the traditional sense, but a second information-processing pass over the same features, tested as a hybrid alongside the numeric ensemble. See Tabs 02–03.

Current best

The core ensemble, with real signal added

An ensemble of XGBoost, Random Forest, and Logistic Regression (simple probability averaging) over cell event-history features (recency-weighted counts, spatial spillover, momentum) plus real GDELT country-week tone/volume signal, evaluated under frozen-threshold, never-look-ahead validation. Still the best-performing configuration found across every approach tested — see Tab 03 for the numbers.

Ranked by what actually moved the needle

Every approach tried, verdict included

Real GDELT signal added to the core ensembleBest result — real, meaningful gain

+1.6 points precision (10-day), +2.4 points (14-day) at the frozen-threshold operating point. A genuinely different, faster-reacting signal source did what further slicing of UCDP's own event history could not.

Two-stage severity modelFixed a completely broken result

P(severe) = P(any event) × P(severe | event occurs), second stage trained only on the far-less-imbalanced "event occurred" subset. Took severity prediction from 0%/0% (single-stage) to 100% precision at 0.1% recall (10-day) and 59.2% at 3.9% (14-day) on real holdout data.

ICL/LLM hybrid reasoning layerReal, modest gain — with an honest failure mode

Accuracy on a 30-case real holdout sample rose from 46.7% to 53.3%, correcting 6/10 false alarms by reading a falling event-count trend as de-escalation — but losing 5/10 true hits to the same heuristic in genuinely ambiguous cases.

Graph-diffusion spatial featuresSmall, mixed

Multi-hop propagation over the cell-adjacency graph (reusing the parent project's own label-propagation approach). Flat at 10-day (+0.1 point), a small real gain at 14-day (+1.1 points). Directionally positive, not decisive.

Hawkes-kernel intensity + CUSUM changepoint featuresNegative — a real, informative result

Self-exciting exponential-decay intensity (the academic standard for this class of problem) and a formal changepoint statistic, in place of round 3's fixed-window counts. Slightly worse at both horizons (10-day −0.6 points, 14-day −0.9 points) — evidence these engineered reformulations were highly redundant with features already in the model, not carrying new information. See Tab 04 for why this matters.

Multi-task joint occurrence+severity modelUnderperformed the specialized two-stage approach

One shared model (3-class objective: no event / event / severe event) instead of two sequential specialized ones. Occurrence precision dropped 6–7 points versus the dedicated occurrence model (65.2%/66.4% vs. 72.3%/73.9% on holdout); severity results were roughly comparable to the two-stage fix, not better. The "smarter-sounding" unified architecture lost to two well-scoped specialized models.

The pattern across every approach tested

New signal sources help; recombining the same one doesn't

Line up every lever tested by what it actually changed: GDELT (a wholly independent, news-derived source) produced the largest real gain. Graph diffusion (multi-hop propagation of the same UCDP event counts) produced a small, partial gain. Hawkes-kernel and CUSUM features (mathematically more sophisticated reweightings of the same UCDP event timestamps) produced a slightly negative result. The pattern is consistent: value came from adding genuinely independent information, not from more sophisticated ways of looking at information already in the model. This is the single most important finding across rounds 3–5 for prioritizing future work — it says PRIO-GRID and CHIRPS/WorldPop (independent sources) are worth far more effort than further UCDP-event-log feature engineering, no matter how principled the technique.

Why "smarter" architecture lost

The multi-task model's failure is informative, not just a null result

A single shared model asked to jointly predict occurrence and severity did worse at occurrence than a model built to do only that job. The likely mechanism: the 3-class training objective spends some of its capacity distinguishing "severe" from "not severe" among positives — capacity a dedicated binary occurrence classifier spends entirely on the occurrence question. Two narrow, specialized models beat one broad one here, which argues for keeping the two-stage architecture rather than "simplifying" toward a unified model in future rounds.

Why recall stays low everywhere

A precision-first threshold, a steep PR curve, and real timing noise

Across every configuration tested, recall sits in the single digits to low twenties. This is mechanically downstream of choosing a threshold that hits 80% precision — the PR curve for this task decays fast (88% precision at 8% recall, down to 59% by 39% recall in the pooled search), meaning only a small slice of real positives are separable enough from the negative class to clear a high bar. Compare the country-week model elsewhere in this project (84% precision at 56.8% recall) — that task aggregates away exactly the cell-level, day-level timing noise that caps recall here. Finer granularity is intrinsically a harder precision/recall tradeoff, not a modeling shortfall.

The severity ceiling

Two-stage fixed precision; recall is still the open problem

The two-stage restructuring turned a broken model into a working one on precision, but usable recall (0.1%–3.9%) is still far too thin to be operationally useful. The features driving both stages are the same event-count/spatial signal used for occurrence — they were never designed to carry severity-specific information (actor capability, weapon type, targeting intent). Real recall gains for severity most likely require features that don't exist in this project yet, not further tuning of the two-stage architecture itself.

Prioritized

What's next, given everything found so far

  1. 1

    Finish and evaluate WorldPop and CHIRPS

    Both are independent, structural/physical signal sources — exactly the category this round's analysis shows actually moves the number. In progress as of this writing.

  2. 2

    Resolve the UNHCR country-code gap

    Myanmar, Sudan, Eritrea, and Haiti returned zero records under their standard ISO3 codes — worth checking UNHCR's own country-code table directly rather than assuming standard ISO3 applies everywhere.

  3. 3

    Get PRIO-GRID covariates via a manual download or browser automation

    Confirmed three times now as the highest-confidence remaining lever this project cannot reach on its own — a genuinely independent, structural signal type in the category that's actually been shown to help.

  4. 4

    Build severity-specific features, not just severity-specific models

    The two-stage architecture is validated; what it's fed is not yet suited to the severity question specifically. Actor-history and prior-fatality-pattern features, not more event-count reslicing, are the next lever for severity recall.

  5. 5

    Feed GDELT context into the ICL/LLM layer

    The hybrid's one clear failure mode (over-trusting a falling count as de-escalation) is exactly the kind of ambiguity real GDELT tone/actor context could help the model reason through, now that signal is already joined into the pipeline for the numeric model.

  6. 6

    Stop investing further in UCDP-event-log-only feature engineering

    Momentum, wider spatial radius, Hawkes kernels, CUSUM, and multi-hop diffusion collectively moved the needle by roughly a point, with one outright negative result. This category of work has a demonstrated low ceiling; new-signal-source integration is the better use of further effort.
