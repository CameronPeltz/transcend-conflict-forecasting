Source

Where the 858 test predictions actually come from

The ground truth is UCDP GED v25.1 (Uppsala Conflict Data Program, Georeferenced Event Dataset) — a real, hand-curated, fatality-coded conflict-event dataset published by Uppsala University, downloaded with no authentication from ucdp.uu.se. It is not a Kaggle dataset and was not scraped from anywhere unusual; it's the primary academic source most secondary "conflict prediction" datasets are themselves built from. The full download is 385,918 real events across 124 countries, 1989–2024. This evaluation uses a 19-country subset (see below), aggregated to one row per country per week, with a real fatality count, event count, and dyad (armed-actor-pair) count per row.

Not all 19 named countries actually appear in this test set — and that's a real, explainable data fact, not an error

The panel is built from a 19-country list spanning DARPA's three named regions. But UCDP only records events where real armed conflict actually happened — a country with no recent conflict activity contributes no rows once its trailing window runs dry. Checking directly:

  • Uzbekistan (UZ): UCDP records events there only 1999–2009. Zero rows after 2021 — real conflict activity, just from over a decade before this test window.
  • Nicaragua (NU): UCDP records events there only 1988–1990 (the Contra war era). Zero rows after 2021 for the same reason.
  • Eritrea, Tajikistan, Kyrgyzstan, Bolivia: present in the earlier (threshold-selection) window but their recorded conflict activity ends before the 2023-08-14 holdout window begins, so they contribute zero rows to the 858 held-out predictions specifically.

Disclosure

The 37.8% base rate in this window is elevated, not representative

324 of 858 real predictions are true escalations — a 37.8% base rate. That's much higher than the roughly 15–17% base rate cited elsewhere in this project for UCDP broadly. Why: this specific 17-month holdout window (August 2023 – December 2024) happens to fall during genuinely intense, real, concurrent conflicts in several of the 13 countries present — Sudan's civil war (since April 2023), Myanmar's post-coup civil war, Ethiopia's Amhara/Oromia conflicts, and Ecuador's 2024 gang-violence emergency all overlap this window. That's not a data-selection artifact — the holdout window is fixed by the temporal split, not chosen to land on a favorable period — but it does mean 84% precision against a 37.8% base rate is a smaller relative improvement over "always guess yes" than 84% precision would be against a 15% base rate, and a reviewer should read the number with that context, not against an assumed global baseline.

Model

What's actually making these predictions

A three-way ensemble — the simple average of a gradient-boosted tree model (XGBoost, 150 trees, max depth 3), a random forest (300 trees, max depth 4), and a logistic regression, each retrained from scratch at every rolling-origin fold. This is not the in-context-learning/LLM forecaster described under Criterion 1 — it's a standard tabular ensemble. That distinction matters for tab 04: this model doesn't produce natural-language reasoning the way the LLM-based forecaster does, so every "explanation" in the case studies below is this document's own post-hoc analysis of the real feature values, not something the model itself generated or "said."

The eleven real features (plus country identity)

Per country-week: event count and total UCDP-recorded fatalities, each as a 1-week lag, 2-week lag, and week-over-week delta; fatalities-per-event, state-based-violence share, and distinct-armed-dyad count, each as a 1-week lag and delta. Country is included as a one-hot categorical feature (see tab 05 for why that matters to how this result should be read).

Precisely

What "predicting a week ahead" actually means here, stated exactly

Each row's features reflect everything known through the end of week W — including week W's own fully-realized event and fatality counts, which is legitimate (by the end of week W, week W has already happened) and not a leak. The label being predicted for that row is whether week W+1 — the following week — sees a statistically unusual spike, defined precisely as: that country's own event count or fatality count in week W+1 exceeding its trailing historical average by more than one standard deviation. This is a relative, per-country statistical threshold, not an absolute casualty count — a country already averaging heavy weekly casualties (like Sudan) needs a real jump in its own recent pattern to trigger a positive label, not just a high raw number. Tab 04 shows exactly why this distinction matters for reading the case studies correctly.

Verified

The temporal-integrity check, re-run independently for this page

Re-read directly from scripts/precision_threshold_validation.py while writing this page: at every fold, train = panel[panel.week < cutoff] — a strict less-than, real calendar time, no exceptions. The alert threshold itself (0.867 on the model's raw probability output) was chosen using only the earlier 1,627 predictions (2021-08-02 through 2023-08-07), then frozen and applied unchanged to the 858 later predictions this page is about. Independently re-deriving that threshold from the raw CSV during this review reproduced the identical value (0.8672483082014172) to 10 decimal places — the threshold-selection step is exactly reproducible, not something written down after the fact.

Real, checked against real news events

Three true positives, with the actual UCDP events behind them

Each case: the model's input was everything known through week W; the target was whether week W+1 would spike. All three below are real true positives from the 858-row holdout — high-confidence correct calls, cross-checked here against the actual raw UCDP event records (not just the aggregated panel) for what happened in the predicted week.

Ethiopia — input week of 2024-10-07, predicting the week of 2024-10-14

p = 0.978

What triggered the real label: not a fatality spike — an incident-count spike. Week of 10/14 saw 29 distinct UCDP-recorded violent incidents against a trailing baseline of ~2.7/week (z = 4.79). Fatalities that week (90) were actually unremarkable against Ethiopia's own volatile baseline (z = −0.04) — this is the honest nuance: the real signal here was how many separate violent incidents occurred, not total deaths.

Real UCDP events, week of 2024-10-14: 9 Government-vs-civilian incidents, 9 Government-vs-OLA (Oromo Liberation Army) incidents, 8 Government-vs-Fano (Amhara militia) incidents — three simultaneous, separate conflict fronts active in the same week. Source: UCDP GED v25.1, dyad_name field, cross-checked directly against results_v2/precision_validation_track_c_predictions.csv for this page.

What the model actually saw going in: the input week (10/07) already showed a jump to 31 incidents/220 deaths from the prior week's 19/90 — a real, large week-over-week increase that plausibly carried forward into elevated risk.

Myanmar — input week of 2023-11-06, predicting the week of 2023-11-13

p = 0.977

What triggered the real label: both signals at once — event count z = 5.06 and fatality count z = 2.84, the cleanest of the three cases. This week falls squarely inside the real, globally reported "Operation 1027" period, when multiple ethnic armed organizations launched coordinated offensives against Myanmar's post-coup military government.

Real UCDP events, week of 2023-11-13: fighting recorded against the Kachin Independence Organization (Tigyaing area), the Karenni National Progressive Party (Loikaw — including 34 deaths in one recorded incident in Loikaw town itself, part of the real, documented siege of Loikaw that November), and the Karen National Union. 48 total incidents, 179 total fatalities that week.

Sudan — input week of 2024-06-03, predicting the week of 2024-06-10

p = 0.960

What triggered the real label: event-count spike again (z = 2.10), not fatalities (z = 0.06) — Sudan's own baseline is so consistently severe (trailing mean ~59 deaths/week) that a 70-death week doesn't statistically stand out, even though it's a real, terrible week by any absolute measure. The incident-count rise is the genuine early-warning signal.

Real UCDP events, week of 2024-06-10: continued RSF (Rapid Support Forces) vs. Sudanese Armed Forces fighting concentrated in El Fasher, North Darfur — including a single incident on 6/11 recorded across "Tambasi, the Grand Market vicinity, Basharia, Baringia, Awlad al-Reef, al-Thawra, and Mukarka" neighborhoods (35 deaths), plus fighting reaching Sinnar (20 deaths, 6/13) and Khartoum. This is the real, documented siege of El Fasher, still ongoing as of the most recent UCDP data used in this project.
Also real, and just as important to show

Two false alarms — where the model was wrong with high confidence

35 of the 219 flagged weeks were false alarms. The two highest-confidence wrong calls: Ethiopia, week of 2024-12-23, p = 0.967 (no real spike materialized that week); Myanmar, week of 2024-11-11, p = 0.965 (same). No attempt was made to find a flattering explanation for these — they are simply real instances where a currently-volatile country's recent pattern suggested continued escalation and it didn't materialize that particular week. This is exactly what the 84.0%-not-100% precision figure already discloses; these are two concrete instances of it.

Direct answer

Was anything in the Criterion 2 claim a hallucination or a lie?

  • ✓
    The core numbers (precision, recall, specificity, accuracy, n) are real and independently reproducible. Recomputed from scratch from the raw prediction CSV for this page, with no reference to prior calculations — they matched to two decimal places.
  • ✓
    The no-leakage, frozen-threshold methodology is real and verified as described. The training cutoff is a strict less-than on calendar week; the threshold was independently re-derivable from only the earlier window and matched exactly.
  • ✓
    The case studies are real, specific, and cross-checked against the underlying raw UCDP event records (dyad names, locations, individual incident fatality counts) — not just the aggregated panel numbers, and not invented illustrative examples.
  • △
    Not disclosed in the proposal text itself, though not hidden either: only 13 of the 19 named countries appear in this specific holdout window (6 have no UCDP-recorded conflict activity extending into it), and the 37.8% base rate in this window is elevated relative to the ~15–17% typically cited elsewhere in this project. Both are visible to anyone who opens the CSV, but neither is stated in the proposal's own prose — a reviewer who checks closely will notice the gap between what's said and what's shown.
  • △
    "Independently validated" needs to be read precisely, not loosely. This is temporally out-of-sample self-validation with real, reproducible methodology and an independently-produced ground-truth label source (UCDP, not the proposer) — not a third-party audit. The proposal itself says this explicitly in the Criterion 2 text; this page confirms that framing is accurate and shouldn't be allowed to drift toward implying more than that in conversation or a verbal pitch.
  • △
    Country identity is a model input. Because the model sees which country it's looking at, part of its precision plausibly reflects "this country is already a known active conflict zone" rather than pure week-to-week signal. The proposal's separate Criterion 4 (leave-one-country-out testing, country identity deliberately excluded) is the correct place to look for evidence the model has genuine transferable signal beyond country-level base rates — this page's result and that one answer different questions and shouldn't be conflated.
  • △
    The case-study "explanations" are this document's own post-hoc analysis of real feature values, not model-generated reasoning. This is a tabular ensemble (GBM + random forest + logistic regression), not the LLM-based forecaster from Criterion 1. It outputs a number, not a rationale — anywhere a write-up describes "why" a prediction was made for this model, that's an analyst's interpretation of the real underlying data, and should be labeled as such, which this page does.
Net assessment

That the headline number holds up under direct inspection — the precision, recall, and methodology are exactly what they're claimed to be, recomputed independently and matched.
