Directly answers the original concern: the "120 events" sample was real but tiny. It's now one of three tracks, always reported separately, never diluted into a pooled number.

2. Two new graph-native model families, both verified working end-to-end

  • Hypergraph neural network (scripts/hypergraph_model.py) — a real, from-scratch (numpy/scipy.sparse, no torch installed in this environment) 2-layer HGNN with real backprop, trained per fold. Hyperedges connect country-weeks by shared country, shared region-week, shared calendar week (global shocks), and shared real actors (GDELT Actor1/Actor2 codes, or UCDP side_a/side_b). This is the first model in the whole project that actually traverses a graph rather than flattening graph statistics into a tabular feature — model-battery-results.html from the prior round explicitly flagged that gap ("none of these five models actually traverse the graph yet").
  • Graph-based label spreading (scripts/graph_nlp_features.py) — a kNN similarity graph over country-weeks with known labels diffused to unlabeled/test weeks via sklearn's LabelSpreading. Early numbers below are the most interesting finding so far (see the calibration callout).

3. Graph-based NLP: a real theme co-occurrence graph, embedded

A 3-year, 19-country GDELT GKG pull captured 662,355 real theme-co-occurrence pairs across 813,624 (country, week, theme) rows. That co-occurrence graph was turned into dense per-theme embeddings via PPMI + truncated SVD (the same family of method as GloVe/LSA, applied to GDELT's theme taxonomy instead of a word-context window), then aggregated into a 12-dimensional embedding per country-week — a new gkg_embed feature block distinct from the old single fragility-share scalar.

4. Real local LLM wired in — no API key, no per-call cost

The ICL forecaster (the RFP's actual named required mechanism) now calls your local Ollama llama3.1:latest first, confirmed with real ~10s/call inference producing genuine calibrated probabilities and reasoning paragraphs — falling back to Anthropic-if-a-key-is-set, then the documented heuristic, in that order. Kept out of the 1000+-iteration bulk sweep (too slow at that scale) and run instead as a dedicated smaller track for the eventual case studies — that job is running now (see status block above).

5. Dangerous-ideas log written

The single most interesting early signal: graph-based label spreading is currently topping Track A's leaderboard on average precision (0.347, vs. the prior round's best-ever comparable AP of 0.256) — but at recall = 0.000 at the standard 0.5 threshold. It ranks the true escalation weeks higher than everything else tried so far without ever actually crossing the decision threshold to flag one. That's the calibration-vs-decision-usefulness tension this project's expert-panel review flagged before, now showing up concretely in a brand-new model family. Whether that holds up, and what threshold would actually make it useful, is exactly the kind of question 1000+ iterations is meant to pressure-test rather than something to conclude from 3 data points.
Track B's early numbers (AP around 0.13–0.17) are lower than Track A's best, on a much bigger and more diverse 19-country sample — a real, honest reminder that "more data" doesn't automatically mean "higher headline score," especially before the search has tried region/graph/hypergraph features on this track yet (only the first few anchor/ablation configs have run so far).
